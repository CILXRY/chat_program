CLIENT SETTINGS

客户端设置

连接你的服务器，并决定 Nebula 在 Windows 上的行为。

服务器

选择连接到远程自托管服务，还是本机运行的服务。

安装版

需要 HTTPS；自签名证书需先安装服务器根证书。

客户端不会自动启动 Docker，请先在项目目录运行 docker compose up -d。

Windows 行为

这些设置保存在本机，不影响服务器上的其他成员。

原生媒体管线

Tauri / WebView2 只负责界面；屏幕采集与音频策略由原生层完成。

WGC / DXGI
Windows Graphics Capture 屏幕 / 窗口采集
FP16 scRGB → ACES tone mapping → sRGB
WASAPI loopback 系统声音
AEC / VAD / RNNoise / DeepFilterNet / AGC 在 Web Audio 链中运行

全局快捷键

首版使用固定组合；如果被其他程序占用，会显示为未注册。

更新

客户端基于 GitHub Releases 更新；Web 页面随服务器更新，无需重装。
